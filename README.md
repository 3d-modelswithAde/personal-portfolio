# Adediwura Afolabi — Portfolio

Personal portfolio website showcasing product marketing, go-to-market, growth, and engineering case studies.

## Case Studies Included

- **Ovie’s Kitchen** (`/ovies-kitchen/`) — From a dormant account to 250+ paid transactions
- **BootClass** (`/bootclass/`) — Marathon Revision Class: 500+ reached, 300+ enrolled
- **Smart Systems Research Laboratory** (`/smart-systems/`) — A 4-degree-of-freedom robot arm, modelled in SolidWorks

## Tech Stack

- Pure static HTML5, CSS3, and vanilla JavaScript (zero runtime dependencies)
- Self-contained media assets and interactive charts/tables
- Configured for Vercel static hosting (`vercel.json`)

## Local Development

You can preview the site locally with any static file server:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Deployment

Deployed automatically on Vercel as a static site from the root directory.
